A continuación, vamos a implementar el patrón de diseño Composite.
Este patrón de diseño se utiliza para tratar un grupo de objetos de manera similar a un objeto individual.
Sin embargo, este patrón es particularmente útil cuando se trabaja con estructuras de datos jerárquicas,
permitiendo a los clientes tratar objetos individuales y composiciones de objetos de manera uniforme.
El patrón Composite permite componer objetos en estructuras de árboles para representar
jerarquías y facilita a los clientes el manejo de objetos.
La implementación define una interfaz común para clases individuales y sus composiciones,
como por ejemplo una clase Live puede representar un objeto individual y las clases Composite
representan grupos de objetos Live.
Los clientes interactúan con la interfaz común, lo que les permite tratar a los
objetos individuales y compuestos de la misma manera. Para poder implementar este archivo,
