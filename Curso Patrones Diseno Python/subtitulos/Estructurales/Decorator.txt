En esta ocasión vamos a programar el patrón estructural decorador. El patrón de diseño
decorador en Python permite agregar funcionalidades adicionales a un objeto de forma dinámica,
es decir, sin alterar la estructura de la clase existente. Este patrón de diseño es útil
cuando queremos extender la funcionalidad de objetos individualmente y de manera transparente.
Para poder implementar este patrón de diseño, por lo general se utilizan cuatro ficheros,
pero hay múltiples estructuras que se pueden utilizar. En primer lugar,
el fichero Component es la interfaz para los objetos que pueden tener responsabilidades
añadidas dinámicamente. Concrete Component es una clase que implementa el componente,
definiendo un objeto al que se pueden añadir responsabilidades adicionales.
