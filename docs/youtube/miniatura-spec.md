# Especificación de miniatura

| Elemento | Especificación |
|----------|----------------|
| Tamaño | 1280 x 720 px (16:9), PNG o JPG, menos de 2 MB |
| Fondo | Oscuro (negro o azul muy oscuro, p. ej. #0D1117), sin degradados recargados |
| Acentos | Cian (#00E5FF) y amarillo (#FFD600); un color para el texto principal y el otro para resaltar una palabra |
| Texto | Máximo **4 palabras**, tipografía gruesa sans-serif, legible a 168 x 94 px (tamaño de sugerencia móvil) |
| Elemento visual | Un solo foco: fragmento de código (5-8 líneas, fuente grande) **o** una gráfica destacada (curva de precios, animación del algoritmo, diagrama del patrón) |
| Márgenes | Dejar libre la esquina inferior derecha (ahí YouTube superpone la duración) |
| Rostro | Opcional; si aparece, recortado a la derecha, sin tapar el código/gráfica |
| Coherencia | El texto de la miniatura complementa el título, no lo repite |

Para Shorts no se exige miniatura propia; elegir un fotograma con el elemento visual claro.

Checklist rápido: ¿se entiende en 2 segundos?, ¿contraste alto?, ¿4 palabras o menos?, ¿sin promesas de ganancias en videos de trading?
