# Fórmulas de título

Reglas: máximo 100 caracteres (idealmente 60-70 para que no se corte en móvil), la palabra clave principal al inicio, sin mayúsculas gritadas, sin promesas que el video no cumpla (en trading: nunca prometer rentabilidad).

| # | Fórmula | Ejemplo |
|---|---------|---------|
| 1 | **Cómo + resultado + herramienta** | Cómo automatizar tareas con N8N y Docker (paso a paso) |
| 2 | **Tema en N minutos** | Patrón Singleton en Python en 8 minutos |
| 3 | **Error común / mito** | El error que arruina tu backtest (y cómo evitarlo) |
| 4 | **Antes vs. después / comparación** | Python lento vs. C++: 100x más rápido con una librería propia |
| 5 | **Construye X desde cero** | Algoritmo genético desde cero: mira cómo evoluciona una recta |

Variantes para Shorts: una sola idea + `#Shorts` al final (p. ej. `Una población de rectas que aprende sola #Shorts`).

Para el curso de patrones de diseño usar el formato fijo `Patrón <Nombre> en Python | Curso de Patrones de Diseño (<n>/17)`.

Antes de publicar: el título debe coincidir con lo que se ve en los primeros 15 segundos y con el texto de la miniatura (ver `miniatura-spec.md`).
