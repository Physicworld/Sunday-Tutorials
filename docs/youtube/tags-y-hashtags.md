# Tags y hashtags

## Hashtags (van en la descripción, `hashtags` en el TOML)

- Máximo 15 (si hay más, YouTube ignora todos); usar 3-5. Los **3 primeros** aparecen sobre el título.
- Formato `#Palabra` sin espacios ni guiones; el renderizador los valida.
- Shorts: incluir `#Shorts`.

| Pilar | Hashtags sugeridos |
|-------|--------------------|
| Curso patrones de diseño | `#Python` `#PatronesDeDiseno` `#ProgramacionOrientadaAObjetos` `#DesarrolloDeSoftware` |
| IA local / agentes | `#IAlocal` `#Ollama` `#DeepSeek` `#AgentesIA` |
| Automatización | `#N8N` `#Docker` `#Automatizacion` |
| Trading / backtesting | `#Bitcoin` `#Backtesting` `#TradingAlgoritmico` `#Python` |
| Ingeniería / rendimiento | `#Python` `#Cpp` `#Rendimiento` |
| Heurísticas | `#AlgoritmosGeneticos` `#Matplotlib` `#InteligenciaArtificial` |

## Tags (campo "Etiquetas" de YouTube Studio)

- Ayudan poco al SEO; sirven sobre todo para variantes de escritura. Máximo 500 caracteres en total.
- Incluir: tema exacto (`patron singleton python`), herramienta (`ollama`, `n8n`), variantes sin tilde y en inglés (`design patterns python`), nombre del curso.
- No usar tags engañosos ni marcas ajenas sin relación con el contenido.
